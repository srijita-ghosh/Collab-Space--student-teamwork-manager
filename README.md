# CollabSpace — Student Teamwork Manager

A Flask + MySQL web application for student teams to create workspaces, invite members, assign tasks, set deadlines, and track progress.

## Features

- User signup and login with hashed passwords
- Personal dashboard with task statistics
- Create a team and generate a unique invitation code
- Join a team using an invitation code
- Team leader and team member roles
- Team workspace with member list and task board
- Leaders can create, edit, assign, and delete tasks
- Members can update the status of their own assigned tasks
- Task priority, deadline, and progress tracking
- Profile editing
- Responsive SaaS-style interface
- CSRF protection on forms

## Technology stack

- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
- Backend: Python, Flask
- Database: MySQL
- Database driver: mysql-connector-python
- Authentication: Werkzeug password hashing + Flask sessions

## Requirements

- Python 3.10 or newer
- MySQL Server 8.x (or a compatible MySQL/MariaDB server)
- VS Code or another code editor

## Setup in VS Code

### 1. Extract the ZIP and open the `collabspace` folder

Open the extracted project folder in VS Code.

### 2. Create and activate a virtual environment

**Windows PowerShell:**

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```bat
py -m venv venv
venv\Scripts\activate
```

### 3. Install Python packages

```bash
pip install -r requirements.txt
```

### 4. Create the MySQL database

Open MySQL Workbench, connect to your local MySQL server, open `schema.sql`, and execute the full script. It creates the `collabspace` database and its four tables: `users`, `teams`, `team_members`, and `tasks`.

### 5. Configure environment variables

Copy `.env.example` and rename the copy to `.env`.

Open `.env` and update `DB_USER` and `DB_PASSWORD` to match your local MySQL setup. Also replace `SECRET_KEY` with a long random value.

Example:

```env
SECRET_KEY=a-long-random-secret-value
FLASK_DEBUG=true
COOKIE_SECURE=false
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_actual_mysql_password
DB_NAME=collabspace
```

Do not share your real `.env` file or commit it to a public repository.

### 6. Run the application

Make sure MySQL Server is running, then run:

```bash
python app.py
```

Open this address in your browser:

```text
http://127.0.0.1:5000
```

## Suggested demo flow

1. Sign up as the team leader (for example, Srijita).
2. Log in and create a team.
3. Copy the invitation code shown after team creation.
4. Open an incognito/private browser window and register a second user.
5. Join the team using the invitation code.
6. Log back in as the leader and create tasks assigned to the second user.
7. Log in as the member and update the status of their assigned task.
8. Return to the leader account and show the updated workspace progress.

## Notes

- Invitation codes are generated by the backend and are unique in the database.
- A user can belong to multiple teams.
- The team creator is automatically stored as the leader in `team_members`.
- For this mini-project version, only the leader can create, edit, or delete tasks. Members can update the status of tasks assigned to them.
- Real-time chat, file sharing, collaborative editing, and email notifications are listed as possible future enhancements and are not included in this first version.
